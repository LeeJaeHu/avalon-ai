# 변경 전 원탁 화면 백업

2026-10-02 원탁 중심 흐름 변경 전에 복사한 파일이다. `site/app/page.tsx`와 `globals.css`는 원본과 SHA-256 일치를 확인했다. API·규칙 엔진·AI 진행 코드도 함께 보존했다. 비밀 설정·게임 로그·DB는 포함하지 않는다.

화면만 되돌릴 때는 이 폴더의 `site/app/` 두 파일을 프로젝트의 같은 경로에 복사한다. 단, 예전 UI는 새 TEAM_DISCUSSION 조작을 지원하지 않으므로 완전한 진행 복원에는 함께 보관한 `site/lib/`와 `site/app/api/game/route.ts`도 필요하다. 새 흐름에서 만든 진행 중 판은 예전 엔진에 호환되지 않을 수 있으므로 종료 또는 새 게임으로 전환해야 한다. 기존 Git 이력에서 변경 전 테스트도 복원하고 관련 검사를 다시 실행한다. 복원은 아직 실시하지 않았다.
