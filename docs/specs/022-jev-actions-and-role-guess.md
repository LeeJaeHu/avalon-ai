# JEV 행동 선택과 종료 전 역할 추측

사용자 합의: Gemini는 V3·최근20개 대화·본인의 이전 생각을 사용해 대화하며 생각을 기록한다. JEV는 개인 행동과 공개 발언자를 선택한다. 단계 전이/합법성/결과 집계는 코드가 담당한다. 역할 추측은 세 번째 성공 또는 실패 원정 결과 확인 후, 암살·종료 공개 전에 AI4명을 대상으로 한다. 본인은 채점에서 제외한다.

## 구현 경계
- 새 게임의 행동 모드 `gemini`/`jev`를 기록하고 설정에서 비교 가능하게 한다. 기존 진행 중 게임의 행동 모드는 변경하지 않는다. 새 기본 모드는 JEV이며 발언자 라우팅도 JEV다. 충신 코드 팀 초안 실험은 JEV 모드에서 우회한다.
- JEV의 미사용 발언 의도 분류를 제거한다. Gemini CHAT 출력 계약은 유지한다.
- 개인 선택 요청은 자신의 역할/시작 지식/개인 카드·생각/실제 선택 이력, 최근20개 공개 채팅 및 공개 결과를 제공한다. 진행자는 공개 정보만 받는다. 여러 플레이어의 비밀을 같은 요청에 합치지 않는다.
- 팀 후보는 코드가 모든 합법 조합을 열거한다. 찬반·악의 성공 여부·암살은 고정 합법 후보의 Choice. 선의 성공 선택은 코드로 확정한다. Gemini 사전 분석 호출은 없다. V3에서 출력 계약 앞의 행동 원칙과 기존 캐릭터 원칙을 선택 입력에도 사용한다.
- JEV는 선택/분포/확신도/입력 해시·버전/토큰·비용·지연/대체 여부를 기록한다. thinking을 만들어내지 않는다. 다음 Gemini 대화에 실제 자신의 이전 선택을 제공한다.
- 역할 추측은 게임 상태와 기존 D1 사건에 저장한다. 선택은 1회만 제출하고 종료 전에 정답·정답 수를 응답/진단/모델 입력으로 노출하지 않는다. 최종 종료 후 추측·실제 역할·개별 정오·정답 수·분모·사용자 역할/시작 정보·원정 수·정책/프롬프트/모델/모드 버전을 로그로 제공한다. 역할 분포는 공개 설정과 일치해야 한다.
- 원정 결과 팝업을 먼저 확인한 뒤 추측 팝업을 표시한다. 미제출 상태에서는 다음 단계와 AI 진행을 서버에서 차단한다. 새로고침해도 상태가 유지된다. 결과 팝업/역할 드롭다운은 기존 Radix 컴포넌트와 테마를 사용한다.

## 검증/통과 기준
- 모의 JEV로 네 행동의 유효 선택·잘못된 값/확률/모델/HTTP/시간초과·키 없음의 합법 대체 동작을 검사한다. Gemini 사전 호출0회, 선 카드 호출0회, 맥락20개 및 실제 선택 전달을 확인한다.
- 비밀 경계: 다른 AI 생각·개별 카드·미공개 표·인간 역할 추측은 개인/진행자 입력에 없어야 한다. 허용된 개인 시작 지식은 유지한다.
- 역할 추측은 세 번째 성공/실패에서만 필요하고, 미제출 전이는 금지되며 전부 정답/전부 오답/부분 정답·역할 수·중복/잘못된 시점·모델 추측 접근 차단을 검사한다. 암살 전에는 점수와 정체0건 노출, 종료 후 정확한 채점 및 로그 포함이 통과 기준이다.
- 기존 버전 검사·AI lease/폐기 경로를 유지하고 관련 자동 검사와 전체 Node 테스트, TypeScript, Worker 빌드를 실행한다. 브라우저에서 결과→추측→제출→종료 및 모바일 드롭다운을 모의 상태로 확인한다.
- 실제 모델의 게임 전략 개선은 이번 자동 검사로 주장하지 않는다. 사용자의 새 플레이 로그를 비교 대상으로 남긴다. 유료 비교 평가의 비용/반복/품질 기준은 별도 합의가 필요하다.

## 지표 해석
`roleGuess.correct / roleGuess.total`은 사용자의 역할 식별 결과다. 시작 역할·정보, 경험과 악의 기만에도 영향받으므로 높을수록 AI 전체가 좋다는 의미로 취급하지 않는다. 버전별/사용자 역할별 원자료를 보존한다. 5연속 부결·중도 재시작에는 추측 미실시로 남긴다.
