# 짧은 페르소나 프롬프트 추가

## 목표와 범위

사용자가 추천된 네 페르소나의 예시를 보여주고 현재 프롬프트에 추가하도록 요청했다. V2 원본 본문은 보존하고 생성된 프롬프트의 공개 정보 직전에 본인 성향과 공통 문구를 넣는다. thinking 지시·폐기 경계와 기존 JSON 계약은 유지한다. 역할과 무관하게 같은 플레이어 ID는 같은 페르소나를 사용한다.

## 구현 전 통과 기준

- 하린/도윤/서아/지호 요청에는 본인 성향만 각각 한 번 들어간다.
- 같은 플레이어의 역할을 MERLIN/LOYAL/ASSASSIN/MINION으로 바꿔도 페르소나는 동일하다.
- CHAT뿐 아니라 모델이 판단하는 PROPOSE/VOTE/CARD/ASSASSINATE에도 같은 성향을 제공한다. scripted·연습·B 초기 계산기 행동은 모델을 호출하지 않아 영향을 받지 않는다.
- 사용자 V2 원문 보존, 역할/개인 정보 치환, 합법적 출력·재시도·thinking 비노출 기존 검사는 유지한다.
- 프롬프트 실행 버전은 V2-persona-v1로 기록해 기존 V2 로그와 구분한다.

## 검증 방법

`node --test site/tests/*.test.mjs scripts/*.test.mjs`, TypeScript --noEmit, 배포 소스 빌드.

실제 모델 호출은 이번 요청에서 별도 승인되지 않았으므로 미실시한다. 기존 9회 대화 후보 평가 승인은 소진됐으며 새 페르소나 평가에 재사용하지 않는다. 자동 검사로 자연스러움·역할별 전략 품질 향상을 주장하지 않는다.

## 배포 범위

기존 배포 소스를 열어 `lib/prompts/personas.mjs`, `lib/prompts/v2.mjs`, 페르소나 검사만 반영한다. 로컬에는 미배포 원탁 흐름 변경이 있으므로 해당 변경을 이 프롬프트 배포에 섞지 않는다. 배포의 AI 정책은 .7, 로컬 원탁 구현은 2026-10-02.8을 유지하며 둘 다 새 promptVersion으로 구분된다.
