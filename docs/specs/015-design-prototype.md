# 원탁 디자인 로컬 프로토타입

2026-10-03. 사용자가 디자인 개선을 시각적으로 판단할 수 있는 로컬 프로토타입을 요청했다. 검토 문서 `../avalon-design-review-2026-10-03.md`의 대화·공개 근거·결정 배치를 먼저 비교한다.

## 범위

기존 앱의 public/design-preview 아래 독립 HTML/CSS/JS로 작성한다. 병행 작업 중인 최상위 prototype 및 Spec 014와 분리한다. 기존 게임 API·DB·모델·프롬프트를 호출하거나 수정하지 않는다. 모든 참가자 발언과 상태는 합성 시연이며 화면 상단에 표시한다. 토론, 투표, 원정 결과, 마지막 암살, 종료 복기를 전환할 수 있다.

어두운 청록·금색을 이어가고, 참가자와 말풍선의 색/문양을 연결한다. 데스크톱은 대화와 공개 기록을 나란히, 모바일은 기록 패널을 열어 비교한다. 역할 목표, 원정 점수, 부결 위험, 현재 결정이 눈에 보이게 한다. 명시적 답장 대상 선택, 팀 변경 제안, 투표, 기록 조회, 역할 보기, 시연 초기화가 동작한다. 자유 입력의 답변은 고정 예시이며 실제 AI 개선을 입증하지 않는다.

## 완료 기준과 검증

- 브라우저에서 로컬 URL HTTP 200과 렌더링을 확인한다.
- 토론→투표→공개 표→임무 카드→결과의 시연, 부결 경로, 암살→복기를 실제 UI로 확인한다.
- 참가자 선택/기록, 역할 열기/닫기, 답장 대상 유지, 초기화와 장면 전환을 확인한다.
- 1280×720 및 390×844에서 핵심 대화·현재 행동·입력을 확인하고 가로 넘침과 주요 요소 겹침을 점검한다. 모바일 화면은 현재 동작의 새 스크린샷으로 확인한다.
- JS 문법 검사와 변경 파일 검사를 수행한다. 실제 게임 규칙/AI 코드 변경이 없으므로 기존 전체 모델/엔진 테스트를 프로토타입 품질 증거로 사용하지 않는다.
- 실패하면 로컬 프로토타입을 수정하고 해당 UI 경로를 다시 확인한다. 배포·실제 모델 호출·사용자 실험은 범위에 없다.

## 결정

단일 프로토타입에서 장면을 전환해 비교한다. 별도 프레임워크·이미지 생성·에이전트 위임 없이 기존 개발 서버가 정적 파일을 제공한다. 기존 게임의 결과 확인 제어를 유지한다. 메모리 안의 상태만 사용해 새로고침으로 초기화된다.

## 구현과 검증 결과

- 주소: `http://127.0.0.1:5173/design-preview/index.html`. 파일은 `site/public/design-preview/index.html`, `style.css`, `prototype.js`이다. 기존 로컬 5173 서버를 재사용한다. 서버를 다시 시작할 때는 기존 README의 `cd site; npm run dev`를 따른다.
- 토론에서 명시적 도윤 답장에 하린을 언급해도 도윤의 예시 응답이 나오는 것을 확인했다. 자유 입력은 저장하지 않으며 고정 답변임을 전송 후 알린다.
- 역할 모달 열기/닫기, 참가자의 공개 기록, 두 명 선택/한 명일 때 제출 비활성, 수정된 명단과 대화 반영을 확인했다.
- 찬성→찬성3/반대2 동시 공개→성공 카드→성공 결과와 기록을 확인했다. 반대→찬성2/반대3→부결 기록 분기도 확인했다. 이는 고정 fixture의 분기이며 실제 AI나 엔진 검증이 아니다.
- 암살 장면에서 수동 결과 확인 후 역할 공개·악 승리·복기를 확인했다. 3번째 결과의 다음 버튼은 중간 원정을 수행하는 대신 마지막 장면 예시로 이동한다고 표시한다. 부결의 다음 버튼도 토론 예시를 다시 열며 실제 연속 대국을 구현하지 않는다.
- 1280×720에서 대화 영역 y=333~527.8(194.8px), 결정 y=527.8~609.6, 입력 y=609.6~679.2로 서로 겹치지 않고 보였다. 390×844에서는 대화 y=382.6~670.3(287.7px), 결정 y=670.3~753.6, 입력 y=753.6~819.2였다. 각 너비에서 document.scrollWidth가 viewport와 같았다. 원본 검토의 결과 화면과 다른 장면이므로 노출 면적의 성능 개선 비율로 비교하지 않는다.
- 모바일 공개 기록 패널 열기/닫기와 화면 캡처 확인. 실제 휴대폰의 가상 키보드·스크린리더·200% 확대는 미실시다. 검증 후 임시 viewport를 해제했다.
- `node --check site/public/design-preview/prototype.js` 통과. 로컬 HTML HTTP 200, 브라우저 console error 조회 0건. 최종 문구/분기 보완 후 새로고침하고 초기 화면·참가자 근거·초기화를 재확인했다.
- 캡처: `docs/review-assets/design-prototype-desktop-2026-10-03.jpg`, `docs/review-assets/design-prototype-mobile-2026-10-03.jpg`.
- 사용자가 시각적 판단을 한 결과는 아직 없음. 모델 품질 개선, 실제 대국 완주, 실사용 접근성 검증, 배포는 미실시다.
