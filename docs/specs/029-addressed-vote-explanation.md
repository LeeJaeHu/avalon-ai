# 지목 질문과 투표 설명

- 사용자 요청: 반대 이유가 일반론에 그치는 문제 개선, 하린에게 서아·도윤을 물었는데 서아가 답한 사례 수정.
- 명시 답장 대상 우선, 이어서 문장 시작의 명확한 존칭/호격 질문 대상 우선. 단순 이름 언급·인용·여러 사람 호명은 기존 의미 판단을 유지한다. JEV가 명확한 수신자를 다른 사람으로 바꾸지 않도록 한다.
- 투표 실행 전 공개 팀·원정·본인 발언을 행동 기록에 연결한다. 미공개 표/카드·역할·thinking은 이 설명 문맥에 저장하지 않는다. JEV의 실제 이유를 추정해 저장하지 않는다.
- Gemini에 최근 본인 투표와 당시 문맥/기존 공개 입장을 제공한다. 과거 판에는 문맥 누락을 표시하며 현재 결과를 과거 근거처럼 쓰지 않는다. 질문의 특정 대상에 먼저 답하고 구체적 우려/확인할 정보/대안을 말한다. 현재 재평가와 당시 기록을 구분한다.
- 자동 기준: 첨부 질문→ai1, 명시 답장 우선, 단순 언급/인용 비강제, 기존 라우팅 회귀; 투표 전 문맥 불변/미공개 정보 제외/자기 기록만 전달/과거 기록 호환. 유료 호출과 형식 검사를 품질 검증으로 혼동하지 않는다.
- 실제 평가안: 고정3상황×기존/개선×Lite/Flash=12회, 재시도0, 예상 비용 상한$0.50. 사용자 승인 전 실행하지 않는다. 질문 응답·공개 근거 일치·구체적인 판단 또는 대안·비밀 누출 없음·과거 이유 날조 없음 모두 충족해야 사례 통과. 비교 수치/원문 없는 판정 근거와 한계를 기록한다.

## 구현 결과
- `discussion-routing.mjs`에서 명시 답장→명확한 문두 존칭/호격 질문→기존 라우팅 순서. 로그 상태 `ADDRESSED_QUESTION`, 라우팅 버전 `jev-discussion-v6-addressed-question`.
- `rememberAction(next,decision,previous)`가 투표 실행 전 공개 문맥을 복사해 저장한다. 본인 최근 투표3개 문맥과 공개 투표4개를 설명 입력에 전달하며 과거 기록에는 null을 유지한다. 당시 선택 이유를 새로 생성해 저장하지 않는다.
- 설명 프롬프트 `V3-grounded-vote-answer-v4`. 실행 중 버전이 바뀐 판은 `runtimeChanged`와 실제 현재 버전을 남기고 모델 비교에서 `runtime-updated`로 제외한다. 새 판의 비교 조건은 새 버전이다.
- 검사: 전체138/138, 운영 소스123/123, TypeScript 및 Worker 빌드 통과. 실제 유료 품질 평가는 승인 응답이 없어 미실시이며 개선율을 주장하지 않는다. 일반 한국어 수신자 해석 전체를 해결한 것은 아니고 첨부 문두 호명 패턴과 명시 답장을 보호한다.
- 배포 소스 `650d1ecf25cb3cb6675c48bfe5f55fddbbf57ffe`, Sites51 성공. 실제 사용자 플레이 확인은 아직 없다.
