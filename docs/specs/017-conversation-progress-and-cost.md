# JEV 대화 진행과 판별 비용

2026-10-06 사용자는 앞서 논의한 대화 중심 JEV 버전, 응답 사용량 기반 한 판 비용 표시, 배포 및 이전 버전 보관을 요청했다.

## 구현 전 계약
- 새 JEV 판에만 conversationVersion=1을 고정한다. 이전 저장 판과 baseline은 기존 진행을 유지한다. 새 게임 기본 선택은 JEV이며 키가 없으면 baseline으로 선택한다.
- JEV Choice의 발언자와 진행 후보를 같은 공개 상태에서 판단한다. 진행 후보 TALK/WAIT/OPEN_VOTE/REVISE/CONTINUE는 현재 상태에서 코드가 허용한 것만 제공한다. 명시 답장은 주소를 우선한다. 사람 미답변 질문은 투표 전환을 막는다. 팀 토론 발언 최소 2회 뒤 투표 예고 가능, 자동 연속 발언 최대 3회, 사건 없는 재검사 최대 2회. 수정 요청은 AI 리더만 최대 1회. 모델 장애는 자동 강제 투표 대신 기존 발언 선택 및 수동 진행 도움을 제공한다.
- 투표 예고 후 6초 유예. 사람 발언/팀 수정은 예고 취소, 입력 중 ADVANCE 중지, 이어서 토론 버튼은 서버 버전이 있는 DEFER_VOTE로 취소한다. 결과는 최소 6초 노출 후 JEV가 CONTINUE 여부 판단한다. 필수 표/임무 카드 완료와 합법적 상태 전이는 엔진만 확정한다.
- 찬반·비밀 카드·사람 리더 팀 구성·암살은 채팅 영역의 행동 카드. 실패 카드는 악·원정 참가자만 표시하며 타인 카드와 미공개 표는 JEV에 전달하지 않는다. 수동 진행 도움 및 일시정지는 남긴다.
- Gemini의 각 전송(재시도 포함)은 usageMetadata의 입력/응답/추론/캐시/전체 토큰을 저장한다. JSON/행동 검증 실패 및 낡은 응답에도 사용량은 보존한다. JEV도 전송 시도별 저장한다. 신규 model_usage 테이블은 시도 UUID로 멱등 기록, 같은 판 모델 생성은 DB 임대로 중복 호출 제한한다. 기록은 키·프롬프트·응답 원문을 포함하지 않는다.
- 판 비용은 확인한 사용량×버전 고정 공식 Global 일반 단가(2026-10-06 Gemini 3.5 Flash-Lite 입력 .30/출력 및 추론 2.50/캐시 .03, JEV 입력 .042, 백만 토큰당 USD). 청구액·리전·중계/인프라 비용과 구분한다. 미확인 사용량/이전 판 기록 불완전 표시. UI에는 공급자별 집계만 공개하고 상세 시도는 종료 로그에 포함한다.
