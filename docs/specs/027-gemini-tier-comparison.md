# Gemini 모델 비용·역할 수행 비교와 배포

2026-10-07 사용자 요청: 직전 진영/역할 채점·시작 역할 분리·5회 부결 추측을 실제 배포판에 반영하고, Gemini 단독/JEV 혼합 대신 Gemini 3.5 Flash-Lite와 상위 Gemini의 비용·역할 수행 트레이드오프를 비교한다. 상위 비교 후보는 Codex가 3.5 Flash로 정한다. JEV 혼합의 우위는 사용자 가설이며 측정된 결론이 아니다.

- 다음 새 게임의 Gemini 모델을 Flash-Lite/Flash에서 선택한다. 기본 Flash-Lite를 유지하고 현재 판 모델은 변경하지 않는다. JEV 발언/행동 구성, 프롬프트, 확률 입력, 게임 규칙과 생성 설정은 두 조건에서 고정한다. 이번 실험에서 바뀌는 것은 대화와 인간 발언 분류 Gemini 모델이다. 기존 Gemini 단독/사용자 구성은 별도 설정으로 유지한다.
- 모델 허용 목록을 서버에서 검증하고 기존 Vertex 중계가 허용 모델만 해당 endpoint로 전달하도록 수정·배포한다. modelVersion과 요청 모델을 사용량에 남기며 알 수 없는 모델 단가는 null로 처리한다. 다른 모델로 자동 바꿔 성공 처리하지 않는다.
- 추정 비용은 Google 공식 Global Standard 입력/출력(추론 포함)/캐시 단가: Lite 0.30/2.50/0.03, Flash 1.50/9.00/0.15 USD/백만 토큰(2026-10-07 확인). 기존 단가 기록은 유지하고 신규 계산 버전을 남긴다. 근거: https://cloud.google.com/gemini-enterprise-agent-platform/generative-ai/pricing ; https://ai.google.dev/gemini-api/docs/pricing
- 종료 로그에 모델 비교 버전 gemini-tier-v1을 보존한다. CLI에 모델별 및 모델 외 동일 조건별 모델 집계를 추가한다. 기존 구성 비교 집계도 보존한다. 새 버전의 JEV 혼합 완료 판만 모델 실험에 포함하며 과거/단독/사용자 구성은 실험 표본으로 섞지 않는다.
- 검증 기준: 요청 모델 선택이 직접 API/중계/분류/재시도/사용량에 일관되게 적용됨; 잘못된 모델 거부; 단가·추론·캐시·모델 경계; 모델별/시작 역할/동일 조건별 분모; 전체 Node/타입/빌드와 합성 PC·모바일 설정·추측 흐름. 중계는 모의 상위 API로 인증·400·허용 endpoint/비밀 경계를 확인한다. 실제 유료 성능 평가는 하지 않는다.
- 기존 운영 source checkout을 공식 workflow로 먼저 갱신하고 관련 파일만 동기화한다. 현재 접근 권한·DB·비밀 환경 변수·진행 판을 유지하며 cloud run과 Sites 배포 성공 ID/URL/소스 SHA를 일지에 기록한다.
- 비용 수집의 기존 결함도 보완한다. 판 상태가 그대로이고 model_usage만 갱신됐을 때도 동기화할 수 있도록 인증된 목록에 사용량 행의 SHA-256 revision을 제공하고 로컬 수집기의 비교에 포함한다. 원문/생각은 목록에 넣지 않는다. 판 ID 순회는 기존 50행 상한을 유지한다. 같은 버전에서 비용 null→확정 시 재수집되고 이후 중복 저장하지 않는 자동 검사로 확인한다.
