# 내 역할 확인 · 이번 판 역할들

2026-10-06. 사용자는 앞서 검토한 상세 역할 설명을 적용하고 버튼 이름을 `내 역할 확인`/`이번 판 역할들`로 지정했다. 확장 계획에 맞춰 브랜드 아래 인원수 문구 제거, 배포 및 GitHub 반영을 요청했다.

- 첫 역할 확인과 게임 중 재확인은 같은 설명 컴포넌트/팝업을 사용한다. 진영·역할 개요·승리 조건·능력·개인 시작 정보·원정 선택·해당 판 예외를 제공한다. 첫 화면 확인만 START를 실행하고 재확인은 상태를 변경하지 않는다.
- 공개 안내는 서버 관찰값의 집계 `roleCounts`만 사용한다. 참가자별 역할표를 보내지 않는다. 역할 수와 선/악 구분, 펼쳐보는 일반 규칙, 판별 예외를 표시한다. 개인 이름 목록은 공개 안내에 전달하지 않는다.
- 금색 배경/테두리의 내 역할 버튼과 보조 안내 버튼을 원탁 위에 배치한다. 모바일은 안내 버튼 행을 따로 배치해 겹침을 막는다. Dialog의 키보드/포커스 기능을 재사용한다.
- 오베론/모드레드/모르가나 예외 문구를 구성에 맞춰 생성한다. 현재4역할 외의 설명은 조건별 단위 테스트로 준비하되, 7인 배정·게임 규칙을 구현한 것으로 간주하지 않는다.
- 역할 창을 읽는 동안 새 AI 진행 요청을 시작하지 않는다. 진행 중 응답이 도착해도 결과/역할추측 창이 겹치지 않고 닫은 뒤 기존 순서를 따른다.

검증: 집계는 배정 순서에 무관하고 이름/개별 역할표를 포함하지 않아야 한다. 4개 현재 역할과 확장 예외 문구, 최초 START와 재확인 무변경, 공개 안내 비밀 미노출, PC/모바일 배치·닫기·기존 결과/추측 흐름을 검사한다. 기존 Node/TypeScript/빌드와 합성 API 브라우저 검증을 실시한다. 실제 모델 호출은 필요 없다.
