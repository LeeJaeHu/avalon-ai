# 게임 종료 후 AI 선택 근거 확인

## 목표와 경계

모델 출력에 thinking과 별개인 `evidence`를 추가한다. evidence는 선택에 대한 짧은 설명·참조 사건·불확실성이다. 자세한 내부 추론을 요청하거나 thinking을 보관하지 않는다. 모델의 자기보고 설명이며 실제 내부 원인을 입증하는 trace로 표현하지 않는다.

근거는 이벤트 detail에만 저장한다. 게임 상태·공개 메시지·플레이 중 GET/POST 응답·진단 다운로드·다음 모델 입력에는 넣지 않는다. 종료 로그와 기존 종료 판 자동 저장에는 포함한다. 기존 판에서 생성되지 않은 근거를 사후 재생성하지 않는다.

## 구현 전 통과 기준

- 모델 스키마에 evidence의 summary(짧은 사유), references(보여준 공개 사건 ID/본인 정보 출처), confidence(LOW/MEDIUM/HIGH)를 포함한다.
- 공개 문맥과 본인 정보로 참조할 수 있는 출처만 허용한다. 자기 역할/동료 악/자기 카드 출처를 타인의 숨겨진 정보로 확대하지 않는다.
- 모델 반환과 행동 필드를 분리하고 이벤트에만 근거를 기록한다. thinking·불필요한 필드는 폐기한다.
- 누락/잘못된 근거는 상태만 기록하고 합법적 게임 행동은 계속 진행한다. 근거 품질 때문에 추가 자동 재시도나 대체를 유발하지 않는다.
- 규칙/계산기/장애 대체는 모델 근거인 것처럼 기록하지 않는다. 대체 암살이 후보 순서 규칙인 경우 이를 명시한다.
- 게임 중 export 거부와 진단의 detail 미포함을 유지한다. 종료 gameLog가 근거를 보존하고 이어지는 프롬프트에는 근거가 들어가지 않음을 자동 검사한다.
- 모델 평가의 새 호출 비용은 이번 요청에서 승인되지 않았으므로 모의 검사·TypeScript·빌드로 계약을 확인한다. 실제 사유의 타당성/불확실성 보정은 미검증이다.

## 출력 예시(실제 판의 사유가 아닌 형식 예시)

```json
{
  "type": "ASSASSINATE",
  "target": "human",
  "evidence": {
    "summary": "후보를 확정할 공개 단서가 부족해, 투표 기록을 바탕으로 한 추측으로 선택했습니다.",
    "references": ["proposal-1", "known-players"],
    "confidence": "LOW"
  }
}
```

원본 V2 TEMPLATE/파일은 보존하고 생성 프롬프트의 출력 안내에 evidence 추가 계약을 넣는다. 새 promptVersion은 V2-persona-evidence-v1이다. 모델이 주장한 근거 참조가 실제 해석을 뒷받침하는지는 사람이 로그 원정·투표·발언과 대조한다.
