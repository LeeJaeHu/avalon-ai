# Gemini 단독 / JEV + Gemini 비교

2026-10-06. 이후 두 구성을 비교할 수 있도록 구현 요청. 실제 유료 실험은 이번 범위에 포함하지 않는다.

- 새 게임 설정에 두 프리셋과 사용자 설정을 제공한다. Gemini 단독은 baseline/gemini, 혼합은 jev/jev이며 대화는 공통 Gemini다. Gemini 단독의 발언자 선택은 기존 규칙임을 명시한다.
- 프리셋은 NEW에서 서버가 두 모드를 함께 확정한다. 현재 판에는 영향을 주지 않는다. JEV 미연결 시 혼합 모드는 실패하고 현재 판을 보존한다. 기존 API의 개별 모드 설정은 유지한다.
- 새 판은 공통 proposalPolicy A, 프롬프트/모델/진행 규칙을 유지한다. 비교 버전과 구성은 aiConfig 및 종료 로그에 보존한다. 오류 시 대체 행동 기록은 그대로 남긴다.
- 내려받은 종료 로그를 로컬 CLI로 비교한다. 게임 ID 중복은 제외하며 충돌 사본은 거부한다. 완료/재시작/연습/과거 조건 미확인/사용자 구성을 구분한다. 비용 누락은 0으로 간주하지 않는다.
- 조건별 집계는 사용자 역할·플레이어 수·모델/프롬프트/정책·역할 추측 버전 등을 구분한다. 지연은 호출별 관측값이며 사용자 체감 대기나 한 판 시간과 같지 않다. 승률·역할 추측 점수는 게임 전체 품질의 인과 지표가 아니다.

검증 기준: 두 프리셋 매핑/잘못된 입력, 모의 모델 호출 분리, 로그 구분·중복·불완전 사용량·재시작·점수 미제출, 기존 엔진 테스트, TypeScript/빌드, UI 프리셋과 다음 판 적용을 검사한다. 실제 모델 품질 비교와 유료 호출은 미실시로 남긴다.

사용법: 설정에서 AI 비교 모드 선택 → 새 게임 → 종료 후 게임 로그 다운로드. 다른 모드도 반복 후 `node scripts/compare-models.mjs <로그1.json> <로그2.json>` 실행. 출력은 개인정보/대화 원문 없이 집계와 판별 요약을 포함한다. 두 모드를 번갈아 진행하고 역할별 표본수를 함께 확인한다.

## 2026-10-07 채점 집계 보완
- `guessAccuracy`는 기존 세부 역할 정답률로 유지한다. `factionGuessAccuracy`와 각각의 정답 수/분모/제출 판수를 추가한다. 과거 로그에 추측과 실제 역할이 모두 있으면 진영 채점을 재계산하며 없으면 미확인(null)으로 남긴다.
- `byHumanRole`에 시작 역할별 모드 통계를 제공하고 `byCheckpoint`에 3성공/3실패/5회 부결 경로별 통계를 제공한다. 조건별 상세 집계도 유지한다. 종료 경로별 수치는 처치 이후 결정되는 선택 집단이므로 인과 효과로 해석하지 않는다.
- 검증 기준: 역할·진영 혼동을 구분하는 계산, 과거 로그의 재계산/누락, 시작 역할과 종료 경로별 분모, 중복·미완료 제외를 자동 검사한다.

## 2026-10-07 Gemini 등급 비교로 주 실험 변경
사용자는 구성 비교보다 Gemini 3.5 Flash-Lite와 상위 모델의 비용·역할 수행 트레이드오프를 원했다. `027-gemini-tier-comparison.md`에 구현/검증 계약을 남겼다. 새 판 설정에서 Gemini 3.5 Flash-Lite/Flash를 고르고 AI 비교 모드는 JEV+Gemini로 고정한다. CLI의 `byGeminiModel`은 새 모델 실험 버전의 혼합 완료 판만 포함한다. `byGeminiModelConditions`는 모델만 제외한 같은 조건(사용자 시작 역할·프롬프트·정책·진행·채점·가격·JEV 행동 모델/버전)의 두 모델 통계를 나란히 제공한다. 기존 `byMode`는 구성 비교 자료로 보존한다. 새 모델 실험은 기존 구성 비교의 전체 평균과 섞어 해석하지 않는다.

## 2026-10-07 사용자 충신 고정 실험
- 새 게임 옵션 humanRoleMode=loyal-fixed/random. API 기본값 loyal-fixed, 엔진 createGame의 기존 기본 호출은 random 유지. 기존 판의 배정은 바꾸지 않는다.
- 충신 고정: 사람 충신, AI 멀린/충신/암살자/하수인 각1명 무작위, 리더는 별도로 무작위. 설정은 다음 판에 적용한다.
- aiConfig.humanRoleMode를 생성 사건/종료 로그/비교 조건에 보존한다. 과거 미기록 판은 null로 별도 분류. 사람에게만 모드 표시하고 AI 입력에 실험 모드를 추가하지 않는다.
- 통과 기준: 다양한 난수에서 역할 수/사용자 역할/리더 유지, random의 기존 배정 유지, 잘못된 모드 거부, 고정 정보의 AI 관찰 비노출, 비교 조건 분리, PC/모바일 옵션 전송 및 현재/다음 판 구분. 실제 모델 호출 없이 검증한다.
