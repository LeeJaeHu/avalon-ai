# 5인 아발론 악 역할 사후확률 모형

작성일: 2026-09-30. 구현: `site/lib/belief.mjs`의 `evilPosterior`.

## 목표와 입력

각 플레이어가 **자신의 역할·시작 정보와 현재까지 공개된** 팀 제안, 완료된 찬반 투표, 원정의 실패 카드 수를 보고 다른 플레이어가 악일 조건부 확률을 계산한다. `observe()`의 플레이어별 관찰값만 입력하며 전체 역할표, 미공개 투표와 개인별 원정 카드는 사용하지 않는다. 결과는 화면에서 본인 역할을 펼쳤을 때와 각 AI의 판단 입력에 제공된다.

## 계산

5인 기본 역할표(멀린 1, 충신 2, 암살자 1, 하수인 1)의 서로 다른 배정 60개에 균등 사전확률을 준다. 자기 역할과 시작 시 알려진 악에 맞지 않는 배정은 제거한다. 남은 배정 `r`마다 다음 로그 우도를 더하고, 최대 로그 우도를 빼서 지수화·정규화한다.

베이즈 정리로 정확히 성립하는 출발점은 `P(r | H,I) ∝ P(r | I) P(H | r,I)`다. 기록을 실제 발생 순서대로 분해한다면 각 행동의 확률은 그전까지의 공개 기록도 조건으로 가져야 한다. 구현은 이를 아래처럼 **근사**한다.

`P_model(r | H,I) ∝ P(r | I) × ∏_j P(T_j | r,L_j,s_j) × ∏_j∏_i P(V_ji | r,T_j,i,a_j) × ∏_q P(K_q | r,C_q)`

여기서 `r`은 다섯 플레이어의 역할 배정 한 가지, `I`는 계산하는 플레이어가 아는 자기 역할과 시작 정보, `H`는 공개된 기록이다. 제안 `j`의 `T_j`는 선택한 팀, `L_j`는 리더, `s_j`는 팀 크기, `a_j`는 같은 원정의 몇 번째 제안인지다. `V_ji`는 그 제안에 대해 플레이어 `i`가 낸 찬성·반대 표다. 원정 `q`의 `C_q`는 승인된 원정 팀, `K_q`는 공개된 실패 카드 수다.

- `I`는 후보 역할 배정 `r`과 계산자의 신분으로 결정되므로, `I`와 맞지 않는 배정을 먼저 제거한 뒤에는 행동 우도에 다시 넣지 않는다.
- **제안:** `P(T_j | r,I,이전 기록,L_j,s_j)`를 `P(T_j | r,L_j,s_j)`로 **가정**한다. 리더와 팀 크기는 해당 시점에 정해진 조건이고, 이전 제안·원정·대화가 리더의 팀 선택에 주는 영향은 생략한다. 리더가 누구인지까지 제안 우도로 추정하는 식이 아니다.
- **찬반:** 제안의 리더·순서·이전 기록까지 조건으로 삼아야 하지만, 구현은 제안 팀과 각 투표자, 5번째 제안 여부만 사용한다. 또한 다섯 명의 표가 이 조건에서 독립이라고 **가정**해 한 명당 한 항을 곱한다. 원래 `P(다섯 표 | r,I,제안,이전 기록)`에서 자동으로 나오는 등식이 아니다.
- **원정:** 원정 성패는 실패 카드 수 `K_q`로 결정되므로 별도 우도를 곱하지 않는다. 승인 여부·찬반·이전 기록의 추가 영향을 생략하고 `P(K_q | r,C_q)`로 **가정**한다. 원정 팀 `C_q`는 이미 승인된 제안의 팀이므로 다시 무작위로 선택한 팀처럼 취급하지 않는다.

제안 우도는 가능한 같은 크기의 팀 모두 중 리더가 멀린이면 팀 내 악 수에 `-1.2`, 악이면 `+1.2`, 충신이면 `0`을 곱한 점수의 softmax다. 찬성 우도는 `sigmoid(-0.4 + 1.0×본인 참가 + 1.2×다섯 번째 제안 + 1.0×정보 보유자 부호×팀 내 악 수)`다. 정보 보유자 부호는 멀린 `-1`, 악 `+1`, 충신 `0`이다. 완료되어 공개된 투표만 반영한다. 원정은 선의 실패 카드 확률을 0, 악 각자의 실패 카드 선택 확률을 임시로 `0.65`로 놓고, 팀 내 악 수 `n`과 공개 실패 카드 수 `k`에 대해 이항 우도 `C(n,k) 0.65^k 0.35^(n-k)`를 쓴다. `k>n`인 배정은 우도 0이며 성공 원정에도 악이 있었을 가능성을 남긴다.

정규화된 배정 중 플레이어 `i`가 암살자 또는 하수인인 가중치를 합해 `P(i가 악 | H,I)`를 만든다. 한 플레이어 관점에서 다섯 확률의 합은 언제나 2다. 예를 들어 충신 본인을 포함한 2인 원정에서 실패 카드가 하나면 다른 참가자는 악일 확률 1이다. 1은 행동 경향 추측이 아니라 선이 실패 카드를 못 낸다는 규칙에서 나온다.

## 해석과 한계

`1.2`, `-0.4`, `0.65`는 학습이나 측정 결과가 아닌 **설명용 가정값**이다. 수치는 이 가정 아래의 사후확률이며 실제 악 판별의 보정된 확률이나 모델 성능 지표가 아니다. 모델은 제안·표·카드를 역할과 팀이 주어지면 조건부 독립으로 취급한다. 실제 플레이에서는 이전 결과, 대화, 공동 전략, 사람과 Gemini의 서로 다른 정책이 이 가정을 깨뜨릴 수 있다. 따라서 가까운 확률끼리의 순위나 소수점 차이를 확신 근거로 쓰지 않는다. 발언과 자동 `speechAct`는 우도에 사용하지 않는다.

실제 수치로 쓰려면 판 단위로 분리한 평가 자료에서 역할·단계·팀 구성별 행동 확률을 추정하고, 보지 않은 판에서 로그 손실·Brier 점수·확률 구간별 실제 악 비율을 비교해야 한다. 자기 역할 정보가 다른 관찰자별로 따로 평가한다. 현재는 이 자료와 외부 검증이 없다.

종료된 여러 판에서 계수를 학습하고 학습 전후를 비교하는 절차와 주 지표는 [`005-belief-learning-experiment.md`](005-belief-learning-experiment.md)에 정리했다.

## 검증

`site/tests/belief.test.mjs`는 균등 사전확률, 제안·찬반 반영, 실패의 논리적 확정, 성공 뒤 악 가능성 유지, 멀린의 시작 정보 반영을 검사한다. API는 `observe(game)`에서 만든 사람 관찰값으로만 `evilBelief`를 계산한다. AI도 해당 배우의 `observe(game, actor)`에서 계산한다. 실제 사람·Gemini 플레이에 대한 판별력과 보정 상태는 미확인이다.
