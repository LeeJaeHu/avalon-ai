# 공개 팀·투표·원정 결과 팝업

사용자가 결과 인지를 높이기 위해 팀 지정, 투표 결과, 원정 결과의 팝업과 성공 모션/그림을 요청했다.

팀 초안 공유/수정 시 리더와 원정 멤버, 전원 투표 완료 시 승인/부결·참가자별 공개 찬반·원정 멤버, 카드 전원 제출 후 원정 성공/실패·원정 멤버·실패 카드 합계를 보여준다. 개별 카드 주인·비밀 역할·thinking은 표시하지 않는다. 팀 초안은 아직 투표 전임을 명시한다.

기존 Dialog를 재사용해 포커스 제한·Escape/확인 닫기를 제공한다. 닫기는 게임 전이가 아니며 자동 닫기 없음. 새 사건당 한 번 자동 표시, 같은 세션 재조회/새로고침은 닫은 팝업을 반복하지 않는다. 현재 단계에서는 다시 보기 버튼 제공. 팝업을 읽는 동안 AI 후속 요청은 잠시 기다리며 닫으면 기존 토론/수동 이동을 이어간다. 원정 성공에는 CSS로 짧은 방패/빛 인장 모션, 실패/팀/투표는 다른 아이콘과 제목 사용. reduced-motion에서는 모션 제거. 그림 생성/모델 추가 호출 없음.

구현 전 검사 기준: 공개 상태만으로 데이터 구성; 미완료 표/카드 결과 비노출; 악의적 추가 비밀 필드 무시; 사건 키가 초안 수정/다음 결과를 구분. 자동 Node 검사 + 기존 회귀 + TypeScript/Worker 빌드 통과. 로컬 합성 판에서 팀/수정·승인/부결·성공/실패 팝업, 닫기/재조회/다시 보기 및 AI 요청 재개, 작은 화면 스크롤/닫기 접근 확인. 실제 모델 평가·운영 개선 효과는 이번 작업에서 미실시/미확인.
