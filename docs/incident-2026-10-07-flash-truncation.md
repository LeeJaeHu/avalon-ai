## 원인과 증상 연결
1. `site/lib/ai.mjs:105`는 모델 구분 없이 maxOutputTokens=768을 사용하고 thinkingConfig를 지정하지 않는다.
2. Flash의 내부 추론이 생성 예산 대부분을 소비하고 답변 JSON이 완성되기 전에 MAX_TOKENS로 종료된다. 잘림 자체는 로그로 확정되며, 추론 예산 부족의 연결은 토큰 분포와 코드에서 강하게 뒷받침된다.
3. `site/lib/ai.mjs:119`에서 JSON 파싱 실패를 OUTPUT_TRUNCATED로 분류한다. askGemini 재시도는 temperature만 0으로 바꾸고 출력/추론 설정은 유지한다. 따라서 두 번째 호출도 같은 종류의 실패가 발생했다.
4. `site/app/api/game/route.ts:225` 이후 일반 DISCUSS의 최종 실패는 SILENCE로 적용한다. 이 판은 필수 답변 조건이 없어 대체 CHAT도 없었다. JEV가 발언을 선택한 3회는 생성 실패, 나머지 8회는 WAIT였다.
5. 투표/원정 등은 JEV가 수행하므로 게임은 종료까지 진행할 수 있었다. 발언 생성만 전부 실패한 구조다.
